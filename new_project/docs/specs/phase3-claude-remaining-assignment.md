## B. 剩余任务（必须按顺序执行）

### 任务 1（P0）：建立“旧版规则对账矩阵”与统一差异报告

**目标**：把“看起来像”变成“可证明一致/不一致”。

**要求**：
1. 新增 `docs/specs/legacy-rule-matrix.md`：
   - 对照旧版 PHP 规则来源（至少覆盖 `TaskFunc.php / UnionFunc.php / ShopFunc.php / ReportFunc.php / RankFunc.php / TroopFunc.php`）。
   - 每条规则列出：触发条件、成功返回、失败状态码、失败文案、DB 关键字段影响。
2. 新增 `scripts/compare-legacy-rules.ps1`：
   - 跑一组固定账号样本（含 `test/test`）；
   - 输出 `artifacts/legacy-rule-diff-*.json`；
   - 明确 `match/mismatch` 和差异字段。

**验收**：
- 生成至少 1 份差异报告；
- 报告中每条 mismatch 都能定位到接口和字段。
